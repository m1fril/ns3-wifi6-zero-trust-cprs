# Аналіз цілеспрямованої деградації зв'язку: 30 експериментів

## 1. Анотація
Цей звіт деталізує результати 30 незалежних експериментів, спрямованих на вивчення стійкості мережі при цілеспрямованій відмові двох випадково обраних станцій. Метою було зафіксувати зміну метрик (втрати пакетів) для цільових вузлів та оцінити вплив зменшення конкуренції на інші станції мережі.

## 2. Параметри експерименту
*   **Мережа:** 30 STA, 1 AP (802.11n).
*   **Сценарій:** `targeted_loss`.
*   **Подія:** О 20.0-й секунді для двох випадкових STA потужність сигналу знижується до -80 dBm, а підсилення (Gain) до -100 dB.
*   **Тривалість:** 40 секунд (20с нормальний стан, 20с після аварії).
*   **Кількість запусків:** 30 ітерацій з рандомізацією цільових вузлів.

## 3. Результати аналізу (середні значення)

| Параметр | До аварії (T < 20s) | Після аварії (T > 20s) | Зміна |
| :--- | :--- | :--- | :--- |
| **Втрати цільової STA 1** | 36.22% | **100.00%** | +63.78% |
| **Втрати цільової STA 2** | 31.66% | **100.00%** | +68.34% |
| **Втрати інших станцій (AVG)** | 40.39% | **39.09%** | -1.30% |

## 4. Ключові висновки
1.  **Повна ізоляція:** Механізм деградації через зміну параметрів PHY (TxGain/Power) успішно призвів до 100% втрат для обраних вузлів, що імітує повну апаратну відмову або вихід із зони покриття.
2.  **Ефект розвантаження:** Після "відключення" двох станцій спостерігається невелике покращення (на 1.30%) показників втрат для решти 28 станцій. Це підтверджує гіпотезу про те, що зменшення конкуренції за радіоефір (less contention) позитивно впливає на загальну стабільність мережі, оскільки менша кількість станцій, що конкурують за ефірний час, призводить до меншої кількості колізій CSMA/CA.
3.  **Базові втрати:** Високий базовий рівень втрат (~40%) зумовлений високою щільністю вузлів (30 STA на одну AP) та використанням стандартних параметрів 802.11n, що створює значне навантаження на механізм зворотного відліку (backoff).

## 5. Візуальні докази
Щоб емпірично перевірити статистичні метрики, ми згенерували вертикальні дашборди високої роздільної здатності (інтервал 0.05с) для випадкової вибірки запусків. Ці візуалізації чітко демонструють раптове падіння метрик `SEND/RECV` для цільових станцій рівно на $T=20s$, а також відповідну зміну загального рівня втрат у мережі.
